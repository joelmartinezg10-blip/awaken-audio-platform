## Git rollback - the durable one

Forward-only, keeps history, safe on a shared branch:

    git revert --no-edit cac4421
    git push

To undo BOTH commits:

    git revert --no-edit 7d2565f cac4421
    git push

Do NOT `git reset --hard` and force-push. History is shared with Vercel and
with the deploy record.
